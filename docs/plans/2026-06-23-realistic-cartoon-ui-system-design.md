# 写实卡通三国 UI 系统设计

## 目标

将现有以纯色 Material 控件为主的界面升级为与世界地图背景一致的写实卡通三国游戏风格。页面使用场景图、角色、建筑、功能图标和美术化边框形成明确层次，同时保留 Flutter 渲染的中文、数值、状态和交互。

## 视觉方向

- 主材质：暗红漆木、旧金青铜、羊皮纸、黑铁与青蓝能量光。
- 造型：斜角、军令牌、卷轴、城门、战旗和青铜包角，减少普通圆角矩形。
- 插画：写实卡通三国，细节丰富但轮廓清晰，适合手机小尺寸显示。
- 层次：场景背景 → 氛围遮罩 → 建筑/角色 → UI 面板 → 动态文字与状态。

## 新增美术资产

1. UI 装饰：漆木面板纹理、青铜角花、斜角红金按钮、羊皮纸面板、战旗页签。
2. 功能图标：首页、城池、内政、招募、地图、事件、任务、武将、阵容、背包、设置等约 20 个图标。
3. 建筑入口：官府、农田、市场、伐木场、冶铁场、兵营、校场、酒馆、铁匠铺、书院、驿站、城墙。
4. 武将头像：按阵营与战斗定位生成一组无文字头像，供武将列表、阵容和战斗单位复用。

所有文字、数字、按钮状态和品质颜色由 Flutter 绘制，素材不得包含错误中文或充值内容。

## 通用组件

- `GameSurface`：漆木、羊皮纸、黑铁三种面板，可叠加青铜角花和品质边框。
- `GameActionButton`：红金主按钮、青蓝次按钮、暗红危险按钮，使用斜角轮廓和按压动效。
- `GameFeatureTile`：图片图标、标题、角标、状态光效组成的功能入口。
- `GameResourceBar`：资源图标、数值和增减状态组成的顶部军资栏。
- `GamePortrait`：武将头像、品质框、阵营和兵种徽章。
- `GameSectionBanner`：战旗或卷轴式分区标题。

## 页面分组

- 主页：城池鸟瞰背景，建筑式入口，角色压边，军资栏置顶。
- 城池/内政：建筑插画和卷轴政务卡。
- 武将/阵容/战斗：头像卡、兵种徽章、阵型战场和金属 HUD。
- 背包/任务：物品图鉴格、卷轴任务卡、宝箱奖励区。
- 地图/招募/登录：保留现有构图，统一按钮、边框、页签和图标。
- 设置/帮助/协议：低对比场景背景与高可读羊皮纸/漆木阅读面板。

## 数据与交互

沿用现有模型、路由、服务和存档。新组件只消费现有字段，例如资源数量、武将品质、建筑等级和任务状态。素材加载失败时回退到内置 Material 图标和同色渐变，不阻断操作。

交互加入轻量按压缩放、选中光晕、角标呼吸和卡牌揭示动画，不增加高频或影响性能的全屏粒子。

## 验证

- 所有主要页面使用至少一种新美术组件，而非仅换背景。
- 首页功能入口、建筑、武将卡和资源栏都有图片或图标素材。
- 小屏与 iPhone 17 Pro 尺寸无溢出，返回/关闭按钮遵循安全区。
- 素材均可解码，失败时存在回退。
- `flutter test`、`flutter analyze --no-pub` 和 iOS 模拟器构建完成。
